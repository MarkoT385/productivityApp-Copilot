# Productivity Dashboard

A responsive productivity web application for creating, organizing, and tracking tasks through a dashboard, calendar, and task lists. Built with HTML, CSS, and JavaScript.

## Technologies Used

- HTML5
- CSS3 (responsive layouts, animations, hover effects, and modal styling)
- JavaScript (dynamic task management and calendar interactions)

## How to Run

1. Clone this repository
2. Open `index.html` in your web browser
3. No additional setup required

## Features

- Responsive dashboard for desktop, tablet, and mobile screens
- Create, edit, complete, and delete tasks
- Task fields for title, description, due date, due time, priority, and category
- Automatic `11:59 PM` fallback when no due time is entered
- Task persistence through browser `localStorage`
- Search, filter, and sort task controls
- Calendar view with current, previous, and upcoming months
- Click calendar dates to create tasks and calendar tasks to edit them
- Priority-based colors for high, medium, and low priority tasks
- Category emojis for School, Personal, and Work tasks
- Hover effects, rounded cards, shadows, and animated task forms
